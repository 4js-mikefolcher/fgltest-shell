# fgltest-shell

An interactive command-line test shell for Genero BDL applications, built on
[fgltest](https://github.com/4js-mikefolcher/fgl-test-harness) and the GGC
(Genero Ghost Client) engine.

Start a Genero program, list its fields and actions, fill fields, trigger
actions and check results from the command line — and save what you did as an
fgltest action file to replay in batch.

_Work in progress: the first release is being built._
